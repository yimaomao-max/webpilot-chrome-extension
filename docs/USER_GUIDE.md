## 1. 产品定位

WebPilot AI 不是通用爬虫，而是 **「公开商业信息页」的结构化监控工具**，首要场景包括：

- SaaS **定价页**（套餐名、价格、席位、计费周期）
- **功能对比表**（Plan A/B/C 能力勾选矩阵）
- 公开的 **招聘列表**、**更新日志表格** 等重复行结构

设计目标：让非工程师也能在 3 分钟内，对竞品页面建立 **可长期对比** 的监控。

## 2. 界面导览

### 弹窗（Popup）

| 区域 | 作用 |
|------|------|
| 顶部 quota | 当前套餐允许的监控数量与已用数量 |
| 智能选择 / 扫描表格 | 在当前打开的标签页发起提取 |
| 提取预览 | 可编辑列名；确认前请检查是否有空列或错行 |
| 字段确认面板 | AI 或规则给出的列类型；**确认字段** 后锁定监控语义 |
| 从网址添加 | 无需先打开页面，后台扫描 URL 内表格 |
| 监控任务列表 | 查看上次检查时间、状态；跳转报告 |

### 设置页（Options）

- **AI**：Base URL、Key、模型 — 全部本地保存
- **云端绑定**：配对码同步套餐上限
- **Webhook**：变化推送与测试按钮
- **本地模拟套餐**：未绑定时用于演示 Free/Pro/Team 差异

## 3. 提取模式详解

### 3.1 表格模式（`mode: table`）

触发条件：拾取目标是 `<table>`，或扫描结果中选择了某个 table。

- 使用 `tableSelector` 定位整张表
- 解析 `thead` / 首行表头与 `tbody` 行
- 适合标准 HTML 定价表

### 3.2 列表分组模式（`mode: pick`）

触发条件：点击的是卡片、定价列、功能行等 **重复 DOM 结构**。

- `findGroup` 向上寻找 ≥3 个同 tag 兄弟 → 推断列表容器
- 从样本条目归纳子字段选择器
- 适合非 `<table>` 的 Tailwind / div 定价布局

### 3.3 批量分页

前置：必须先有一次成功提取并得到 `wp_draft.config`。

- 自动查找「下一页」链接（中英文常见文案 + rel=next）
- **请勿关闭标签页**，直至 `wp_paginationJob.status === 'done'`
- 默认最多 10 页，可调至 200；请避免对小型站点造成压力

## 4. 监控任务生命周期

```text
创建 (save monitor)
   → 注册 chrome.alarm (wp-mon-{id})
   → 到期 checkMonitor
        → fetch URL (no credentials)
        → offscreen 解析
        → 字段对齐
        → diffRows
        → 若无实质变化：仅更新 lastRows
        → 若有变化：写入 wp_changes、Badge、Webhook
   → 用户可在列表中删除 / 调整间隔（受套餐 minIntervalMin 约束）
```

### 状态码（`lastStatus`）

| 状态 | 含义 | 建议操作 |
|------|------|----------|
| `ok` | 最近一次检查成功 | — |
| `checking` | 正在进行 | 等待 |
| `selector_broken` | 选择器失效且曾有历史数据 | 重新拾取并更新监控配置 |
| （`needsReconfigure` 标志） | 降级提取成功 | 页面改版，建议重新确认字段 |

## 5. 理解一次「变化」记录

每条记录（存入 `wp_changes[monitorId]`）包含：

| 字段 | 说明 |
|------|------|
| `summary` | 人类可读短句列表 |
| `fieldChanges` | 机器可读，含 `change_type` |
| `insight` | `facts` + `guess` + `category` |
| `added` / `removed` / `modified` | 原始 diff 样本（各截断前 10 条） |

**价格类变化** 在用户将列标为 `type: price` 或值符合货币模式时，会输出 `price_increase` / `price_decrease`，便于后续 BI 或 Zapier 处理。

## 6. 周报是怎么生成的

1. `buildWeekRaw` 取过去 7 天内所有变化
2. 按 `competitorOf(url)`（域名）聚合章节
3. 规则层先写 Markdown 概览与各竞品小节
4. 若配置 LLM 且本周有变化，可附加一段商业解读（失败时仍保留规则版）

定时器：`wp-weekly-report` alarm，周期 7 天；也可在 Popup **立即生成**。

## 7. 常见问题

### Q：动态渲染页面扫不到表？

A：请在 **完全加载后** 使用「智能选择提取」；纯静态监控任务对强 SPA 站点可能不稳定，需要更频繁地重新拾取。

### Q：监控显示无变化，但我肉眼看到改了？

A：可能改的是非监控字段（图片、CSS 文案位）；或变化在监控建立之前。检查是否命中 `selector_broken`。

### Q：AI Key 会泄露吗？

A：Key 只存在扩展本地存储；请求从你浏览器直接发往配置的 API Base。勿在录屏中打开设置页。

### Q：和 Puppeteer / Playwright 爬虫比如何？

A：WebPilot 强调 **低门槛 + 字段级商业语义 + 内置 diff/洞察**，不是替代大规模分布式爬虫，而是让产品/增长同学自助盯公开竞品页。
